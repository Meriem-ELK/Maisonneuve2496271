# Projet Laravel – TP1 : Gestion des Étudiants

## Description de projet

Ce projet est un site internet CRUD (Create, Read, Update, Delete) permettant de gérer les informations des étudiants du Collège Maisonneuve. 
Le projet permet de : 
- Créer de nouveaux étudiants
- Visualiser la liste complète des étudiants 
- Consulter les détails d'un étudiant spécifique 
- Modifier les informations d'un étudiant existant 
- Supprimer un étudiant de la base de données.

##  Fonctionnalités principales

- Interface utilisateur moderne avec Bootstrap 5
- Système de pagination pour la liste des étudiants
- Validation des données côté serveur
- Messages de confirmation pour les opérations CRUD
- Relations Eloquent entre Étudiants et Villes
- Design responsive adapté aux mobiles et tablettes
