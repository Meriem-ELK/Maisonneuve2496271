# Projet Laravel – TP2 : Réseau Social du Collège

## Description de projet

Application web permettant aux étudiants de :

- Se connecter avec leur compte personnel
- Publier et lire des articles sur un forum
- Partager et télécharger des documents (PDF, ZIP, DOC)
- Naviguer en français et en anglais

##  Fonctionnalités

- Authentification sécurisée avec mots de passe cryptés
- Système multilingue (français/anglais)
- Forum d'articles avec gestion CRUD
- Répertoire de documents avec upload et pagination
- Interface responsive avec Bootstrap
- Validation des formulaires
- Autorisation : seul l'auteur peut modifier/supprimer son contenu
